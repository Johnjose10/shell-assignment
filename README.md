
# EC2 Monitoring using Bash

## Objective
Monitor an Ubuntu EC2 instance using a Bash script.

## Tools Used
- AWS EC2
- Ubuntu Linux
- Bash Shell Scripting
- Git and GitHub
- Cron

## Features
- Displays running services
- Displays CPU information
- Displays memory usage
- Displays disk usage
- Saves monitoring output to a log file
- Supports daily automated monitoring

## How to Run
chmod +x monitor.sh
./monitor.sh

## Log Output
./monitor.sh >> monitor_logs.txt 2>&1
